## 3. Flows
### FLOW-001 — Upload a file that already exists
- **Serves:** REQ-001
- **Steps:** 1. Choose file 2. Upload 3. Read "Already uploaded" 4. Open the original
- **Success:** the original file opens in the viewer
- **Failure:** network error → "Upload failed. Check your connection and try again." with Retry
- **Cancel:** Cancel during upload → empty form, nothing stored
- **Recovery:** Retry keeps the chosen file
- **Boundary:** file over 20 MB → size message before uploading

## 4. Page details
### PAGE-001 — Upload
| State | User sees | Words | Can do next |
|---|---|---|---|

| permission | notice, picker hidden | "You can view files but not upload. Ask an admin for access." | go back |
