## 1. Design plan
### Palette
| Name | Hex | Role |
|---|---|---|
| Ink | #1F2328 | text |
| Paper | #FFFFFF | surface |
| Line | #D0D7DE | thin borders |
| Action | #0969DA | primary action, links |
| Caution | #9A6700 | duplicate notice |
| Danger | #CF222E | failure notice |

### Type
| Role | Typeface | Size / weight / line height |
|---|---|---|
| Body | Inter | 14 / 400 / 20 |
| Title | Inter | 20 / 600 / 28 |

### Layout
- One left-aligned column, 640 px max; the result area sits directly under the picker, where the eye already is.

### Principles
- The answer appears where the action was taken; no toast, no modal.
- Hierarchy by thin borders and weight, not shadows.

## 4. Components
### CMP-001 — Notice
- **Variants:** success, duplicate, failure, permission
- **Sizes:** one
- **States:** default, focus (the link), with-action
- **Content limits:** message ≤ 80 characters, file name truncated in the middle
- **Overflow:** wraps to two lines, then truncates the file name
